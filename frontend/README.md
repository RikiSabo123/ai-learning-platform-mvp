# Frontend App

This React frontend uses Vite and connects to the backend API.

- Use `docker-compose up --build` from the project root to build and run the frontend and backend.
- If you run the frontend locally without Docker, install dependencies with `npm install` and start with `npm run dev`.
- The main source is in `src/`, including pages and services.
- Use the UI to select categories, subcategories and send prompts.
